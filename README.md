Repository Contents

This GitHub repository contains the R scripts used for gene expression analysis, cell-type annotation, and the generation of individual figures presented in this study. 
The scripts cover the major analytical workflows and downstream analyses described in the manuscript.

The processed single-cell RNA-sequencing and T-cell receptor sequencing data generated in this study are publicly available on Zenodo:

Zenodo: https://zenodo.org/records/24198467

The processed dataset, named GCdata.rds, contains all cell types analyzed in this study and is available for download from the Zenodo repository.

The raw sequencing data are available through the Genome Sequence Archive for Human (GSA-Human) under accession number PRJCA036458.

All analysis scripts, including quality control, data integration, clustering, cell-type annotation, and downstream analyses, are provided in this GitHub repository.
